# Submitting a new project

1. Make a folder here named after the project, lowercase with hyphens:
   `submissions/tsubaki-20th-anniversary/`
2. Inside it, add:
   - `project.md`: a copy of `_template/project.md`, filled in
   - `renders/`: renders and block-massing views (as many as you like)
   - `photos/`: event photos of the finished build (as many as you like)
3. Tell Claude the folder is ready.

Claude picks the best images (one massing view for the tile, renders and photos for the
project page), resizes them for the web, writes the page from your notes, and removes this
submission folder once the project is live.

Images: JPG, PNG or WebP at full resolution. On GitHub's website each file must be under 25 MB,
and you can drag up to 100 files at a time.
