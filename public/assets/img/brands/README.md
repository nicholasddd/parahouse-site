# Client logos

One logo file per brand, named by its slug plus `.svg`, `.png` or `.webp` (SVG is sharpest).
The site shows each logo in white on the dark background, so any colour version works.
A brand without a file shows its name as a small placeholder. To add or remove a brand,
also edit the BRANDS list in the page generator or the brand-wall `<ul>` in index.html and about/index.html.

Current PNGs were cut from the logo sheet in the 2026 capabilities deck; swap in vector files when available.
